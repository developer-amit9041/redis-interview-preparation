# Redis Interview Preparation

Redis interview questions and answers are separated into two files so the question bank stays clean and answers can be added one by one.

## Files

- **[Redis Interview Questions](./redis-interview-question.md)** — the complete 140-question list organized into 9 levels.
- **[Redis Interview Answers](./redis-interview-answer.md)** — answers in English + Hinglish, with practical examples. Currently includes Q1–Q103, through “How Do You Connect Redis with Node.js?”

## Study Format

Each answer will include an English interview definition, a clear Hinglish explanation, a practical example where useful, and a one-line revision.
